# 🎮 KidsLearn

> A simple and interactive educational mini-game for children, built with SwiftUI for iOS.

KidsLearn is an educational casual game designed to make basic learning concepts more interactive and engaging for young learners.

The game provides multiple learning categories, randomized questions, instant feedback, score tracking, and a final result screen.

## 🎮 Game Features

### 📚 Learning Categories

KidsLearn currently includes four learning categories:

- 🔢 **Counting**
- 🔤 **Letters**
- ➕ **Addition**
- 🔷 **Shapes**

### 🕹️ Gameplay

- 8 questions per game session
- Randomized questions
- 4 answer choices
- Immediate correct/wrong feedback
- Score tracking
- Progress indicator
- Answer selection lock after submission
- Haptic feedback
- Correct-answer sound feedback
- Animated UI interactions
- Final score screen
- Star-based result
- Play Again functionality
